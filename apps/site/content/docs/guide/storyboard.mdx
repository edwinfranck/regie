## Les cases

Le storyboard affiche une case par plan, dans l'ordre du film. Cliquez une case
pour ouvrir le plan ; glissez-la pour la déplacer dans sa scène. L'image d'une
case est l'une des images générées ou envoyées pour ce plan.

Formats des cases : 16:9, 9:16, 4:3, 2.39:1, 1:1.

## La planche multi-cases

Cochez plusieurs plans, puis générez une **planche** (cible `sheet`) : tous les
plans en **une seule image**, chaque personnage décrit une fois, une ligne par
case.

<Callout title="Pourquoi une planche en une passe">
  Dans une seule génération, le modèle dessine toutes les cases avec le même
  personnage. Vingt générations isolées donnent vingt personnages différents.
</Callout>

## Export

Le storyboard s'exporte en **PDF** (planches imprimables, plans avec leur
image) ou en **ZIP** de toutes les images du projet.
