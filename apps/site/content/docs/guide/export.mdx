Chaque export est produit à la demande depuis l'état actuel du projet. Rien
n'est mis en cache : ce que vous téléchargez est ce que vous voyez.

| Export | Formats | Contenu |
|---|---|---|
| Scénario | PDF, Fountain, TXT, DOCX, Final Draft (`.fdx`) | mise en page standard (Courier 12) pour le PDF ; Fountain et Final Draft pour les logiciels d'écriture |
| Projet complet | JSON | concept, histoire, monde, bible, scénario, scènes, plans, storyboards — pour archiver ou réimporter |
| Liste des plans | CSV | un plan par ligne : scène, code, durée, cadre, lieu, personnages, action, dialogue, transition, statut |
| Storyboard | PDF, ZIP | les plans avec leur image en planches imprimables ; ou toutes les images en fichiers séparés |
| Assets | ZIP | tous les fichiers du projet rangés par type, 500 au plus par export |
| Film | MP4, MOV | rendu depuis le [montage](/docs/guide/montage#rendre) |
| Séquence | SRT, EDL | sous-titres et liste de montage, depuis le montage |

Les exports passent par les mêmes droits que le reste : un lecteur peut
exporter ce qu'il peut lire.
