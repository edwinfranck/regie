Le concept est la première page d'un projet. Tout ce qui s'y trouve nourrit le
contexte des tâches IA du projet : l'assistant, les fiches, le découpage le
lisent.

## Les champs

| Champ | Contenu |
|---|---|
| Point de départ | ce que vous savez déjà — l'idée, le genre, le sous-genre… L'IA part de là. |
| Logline | l'histoire en une phrase : qui, veut quoi, contre quoi |
| Tagline | l'accroche de l'affiche |
| Synopsis court, synopsis long | quelques lignes ; une page |
| Pitch | ce que vous diriez en trente secondes |
| Thèmes | étiquettes |
| Conflits, enjeux | le conflit central et les secondaires ; ce qui est perdu si le personnage échoue |
| Univers | le monde en quelques phrases (le détail va dans **Monde**) |

## Proposer un concept

**Proposer un concept avec l'IA** envoie l'idée à un modèle de texte (tâche `concept`). La réponse
s'affiche champ par champ, à côté de vos valeurs : vous appliquez ce
qui vous convient, un champ à la fois ou tout d'un coup. Rien n'est écrit sans
que vous l'appliquiez.

La proposition contient aussi des **personnages potentiels** : **Créer ces
personnages** les ajoute à la bible avec leur rôle et une première
description (ceux qui existent déjà sont ignorés).

<Callout>
  Sans modèle de texte configuré, le bouton est désactivé et le dit. Le concept
  s'écrit alors à la main, comme tout le reste.
</Callout>
