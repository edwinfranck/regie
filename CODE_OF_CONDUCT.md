# Code de conduite

régie adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

En résumé : on se respecte, on accueille les débutants comme les
professionnels, on critique les idées et pas les personnes, et on n'accepte
ni harcèlement, ni discrimination, ni attaque personnelle — dans les issues,
les discussions, les PR et partout où le projet est représenté.

Pour signaler un comportement inacceptable, écrivez aux mainteneurs via les
[avis de sécurité privés du dépôt](https://github.com/edwinfranck/regie/security/advisories/new)
en précisant « code de conduite ». Les signalements sont traités en toute
confidentialité.
